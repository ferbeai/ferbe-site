FINDING DESCRIPTION
User access provisioning lacks formal approval records. New accounts were created without documented authorisation from line managers, contrary to A.9.2.2 requirements.
ROOT CAUSE
No formal access request form in use. IT team provisioning access based on verbal requests from managers.
CORRECTIVE ACTION
Deploy the Access Request Form. Require all new access requests to be submitted via form with manager e-signature prior to provisioning.
